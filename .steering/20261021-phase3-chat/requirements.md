## 決定事項（K 2026-10-21）

- PRD U1 の送り先は「**新しいセッションを起こす**」（Agent SDK と同じ仕組み）。今開いている Claude Code には送らない

## 何ができるようになるか

1. バーの「チャット」で文を打って送ると、ペットが「考え中」になり、数秒〜数十秒で答えが返る
2. 答えは吹き出しに出る。「声で知らせる」がオンなら AivisSpeech で読み上げる（声は Phase 3 の後半。今回は読み上げの口だけ用意し、無ければ黙る）
3. 続けて送ると同じ会話の続きになる。「新しいチャット」で会話を捨てて最初から
4. 設定画面に「チャットの接続: サブスク／API キー」。API キーを選んだら入力欄が出る
