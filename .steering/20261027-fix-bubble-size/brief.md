# 吹き出しの固定文言が長いと切れる（T1 brief・fix/bubble-size）

## 要求（2026-10-27。K の報告・司令塔のセッションから委任）

読み上げの固定文言「マイクを使えないよ（ミュートか Windows の設定）」が、吹き出し（180×40 のカプセル・`white-space: nowrap`）に収まらず途中で切れた。文字数に応じて吹き出しの大きさを調節し、すべての文字が読める状態にする。省略しない。

## 再現

`scripts/verify/render-ui.js` に固定文言のケース 8 つ（短い・K の文・60 字・120 字・200 字・改行入り・URL 入り・英大文字の文）を足し、はみ出しの検査を縦だけでなく横も見るようにした（固定文言は横にはみ出していた＝今までの検査は 0 を返していた）。直す前（main の `bubble.html`・180×40）の実測:

| 文 | 横のはみ出し（px） |
|---|---|
| K の文（25 字） | 49 |
| 60 字 | 241 |
| 120 字 | 529 |
| URL 入り | 223 |

## 直し方

1. **大きさを決める純粋な関数を `pet_core::bubble` に置く**（テスト先行・22 本）。字幅の見積もり → `white-space: pre-wrap; overflow-wrap: anywhere` と同じ折り返し → 島の大きさ
2. **幅**: 1 行に収まるなら文字の幅＋左右 16px（最小 180＝「できたよ」の従来の見た目、最大 320＝承認のカードと同じ。ペットより大きく横へ広がると吹き出しに見えない）。折り返したら 320
3. **高さ**: 上下 10px＋20px×行数（1 行＝40 で従来のカプセルと同じ）。上限なし（省略しない。長い文は折り返して高さで取る＝DESIGN.md の「吹き出し」）
4. **見た目**: 1 行はカプセルのまま。複数行は角丸 16px・左寄せ・`palt` なし（文には掛けない。掛けると句読点が詰まって見積もりと行の切れ目が合わない）
5. **保険**: 見積もりが外れて中身がはみ出したら、`bubble.html` が描画後に `scrollWidth/scrollHeight` を測って `ui_action("bubble:fit:<seq>:<w>:<h>")` で伝え、`ui.rs` が窓を広げる（縮めない。承認のカードは対象外＝行数の上限で「許可」を出さない決まりがあるため）。通し番号 `seq` で古い中身の測定を捨てる。上限 400×600

採った値（常に実測より広い側。狭く外すと切れる）: 全角 13.25（288px の行に実際は 22 字入るが禁則の余地で 21 字）、英大文字 10、m・w 10.5、数字 7.5、その他の半角 7.0。`estimated_width_is_at_least_the_measured_width` が実測以上かつ 1.25 倍以下を固定する。

折り返しの挙動（Edge・`scratchpad/wrapprobe.js`）: 長い語は次の行へ送ってから途中で折る（今の行の残りを埋めない）／「-」の後ろは折れる／「/」「.」「_」は折れない／行末の「、」はぶら下がる／「（」は行末に残らず次の字と一緒に送られる。
