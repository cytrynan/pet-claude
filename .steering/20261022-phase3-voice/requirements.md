# 要求: 声で知らせる・声で話しかける（Phase 3 の後半）

書類の段: **T3**（`state.json` の項目追加＝永続スキーマ、マイクの録音、外部のエンジン（AivisSpeech）とパッケージの導入に触れる）。

K の指示（2026-10-22）「声まわり（Phase 3 の残り）を進めて」。PRD の G3・F16・F17・S11、受け入れ条件「Phase 3: S10・S11 が動く。AivisSpeech 停止中でも落ちない」。

## 何ができるようになるか

1. **読み上げ**: 「声で知らせる」がオンなら、ペットが天深シノ（ノーマル）の声で話す
   - チャットの答え（吹き出しに出した 1 行。吹き出しに出せずチャット欄に回した時は「答えはチャット欄に出したよ」）
   - Claude Code の出来事の固定文言: 「できたよ」「失敗しちゃった」「入力を待ってるよ」、承認のカードが出た時の「確認してほしいことがあるよ」
2. **音声入力**: バーの右のボタンを押すと録音が始まり、話し終えて 1 秒ほど黙ると止まる（もう一度押しても止まる。最長 15 秒）。文字起こしした文をチャットに送り、答えを吹き出しと声で返す（S10 と同じ）
3. 設定画面の「声」に、読み上げのエンジンと音声入力の準備ができているかが出る

## 非スコープ

- ウェイクワード（Phase 4）。ペットごとの言葉の欄と設定画面の表示は別スレッド「ペットごとのウェイクワード」が作る。ここでは触らない
- 声の選択（話者・スタイル・速さ）を画面で変えること。天深シノ・ノーマルに固定
- 答えの全文の読み上げ（長い答えはチャット欄で読む）
- 音声入力の文を送る前に直す画面（§K の Q3 で「そのまま送る」以外に決まったら入れる）

## K に確かめること

- **Q1 文字起こしの道具**: 推奨 A＝faster-whisper（small）を pet-claude 専用の Python 環境に入れ、録音ごとに起こす（この PC で 6 秒の発話が 3.3 秒、モデルは手元にある、ビルドに cmake が要らない）。B＝whisper.cpp を exe に組み込む（Python 不要だが cmake の導入とモデル 466MB のダウンロードが要る）。A は `pip install faster-whisper` を 1 回行う（K の了承が要る）
- **Q2 AivisSpeech のエンジン**: エンジンは 1 つで約 3.4GB のメモリを使う（2026-10-22 実測）。推奨 A＝話す時に動いていなければペットが起こし、10 分話さなければ止める（ペットが起こした時だけ。ai-news と同じ作法）。B＝動いている時だけ話す（PRD F16 のまま。K が自分で起こす）
- **Q3 文字起こしの後**: 推奨 A＝そのまま送る（PRD S11 のとおり。認識した文はチャット欄に K の発言として出る）。B＝チャット欄の入力に入れて、K が直してから送る
- 既定にしたこと（K が違えば言ってもらう）: 録音と文字起こしの間、エンジンの起動中は N1 の対象外（チャットの Q1 と同じ考え方。終われば消える）
