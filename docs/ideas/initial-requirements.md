# pet-claude 初期要件（2026-10-21 K 指示）

## 一言で

ChatGPT デスクトップアプリの「ペット」機能と同じものを、Claude Code 向けに Windows で作る。
声は ai-news と同じ AivisSpeech（天深シノ）。絵は後から作る（最初は仮画像）。

## 画面の挙動（ChatGPT のスクショ 5 枚から）

| # | 状態 | 見た目 |
|---|---|---|
| 1 | 既定 | ペットだけが浮いている（目は半開き） |
| 2 | 右クリック | 「⚙ 設定」「Mini を非表示」のメニュー |
| 3 | 左クリック | ペットの下に小さなバーが出る。左＝チャット、右＝音声入力 |
| 4 | バーの左（チャット）を押す | 「新しいチャットを開始」の入力欄が開く |
| 5 | 質問中 | 上に吹き出し（質問文の冒頭＋「考え中」）、下のバーに ⌃ が増える |

## 必須機能（Phase 1: 土台）

- 透過表示、常時最前面、**フォーカスを奪わない**（作業中のウィンドウからキーボードを取らない）
- **キャラクターの不透明部分だけ**クリック判定（透明部分は背後のウィンドウに通す）
- ドラッグで移動、**画面外へ逸脱しない**（複数ディスプレイの作業領域にクランプ）
- 行動 4 種: 待機・散歩・睡眠・つままれ
- **キャラクター素材と行動ロジックを分離**（絵の差し替えで動作が変わらない）
- Claude Code hooks との連携は**交換可能な入力部分**として設計（hooks 以外の入力源にも差し替えられる）
- **複数画面・表示倍率の違いで先に動作確認**してから本番素材を組み込む
- Claude Code のアプリ（デスクトップ版）を閉じていても動く（独立プロセス）

## Claude Code の状態に対する動き（K 指定 2026-10-21）

| Claude Code の状態 | ペットの動き |
|---|---|
| 待機中 | 呼吸、まばたき、ときどき座り直す |
| Claude が作業を始めた | 起き上がる、手元で作業する |
| ツールを実行中 | 作業アニメーションを続ける |
| ユーザーの操作待ち | こちらを見て、小さく手を振る |
| 応答が終わった | 一度だけリアクションして待機に戻る |
| クリックされた | 喜ぶ、振り向く |
| ドラッグされた | つままれたポーズになる |

## 必須機能（Phase 2 以降）

- 設定画面: ペットの大きさ、音声出力の有無、音声トリガー（ウェイクワード）の有無
- 承認待ち（permission）のとき、ペットの吹き出しから**許可・拒否**を返せる
- 左クリックのバー: チャット（新しいチャットを開始）と音声入力
- 音声出力: AivisSpeech（`127.0.0.1:10101`、ai-news の `lib/radio.mjs` と同じエンジン・話者）
- 音声入力: バーの右ボタンで録音→文字起こし→Claude へ
- ウェイクワード: K の声を録音し、決めた言葉を言うと勝手に音声入力モードに入る（後回し）
