# pet-claude の使い方

画像つきの説明は [マニュアル（PDF）](manual/pet-claude-manual.pdf)にある。ここは手順だけを短く書く。

## 起動する

- 普段は Windows タスク `pet-claude` が、サインインの 10 秒後にペットを出す（設定「サインインしたらペットを出す」がオンのとき）。
- 手で出すときは `pet-app.exe` を起動する。`pet-hook.exe` と同じフォルダに置いておく。
- 設定画面をすぐ開きたいときは `pet-app.exe --open-settings`。
- 別のペットのフォルダで試すときは `pet-app.exe --pet <フォルダ>`。
- 二重には起動しない。すでに出ているときは新しい方が静かに終わる。
- ペットを 1 つも読めないときは理由のダイアログを出して終わる。
- トレイのアイコンを右クリックすると「設定」「位置をリセット」「終了」。

## ペットを操作する

- 左クリック: ペットがなでられた反応をし、下にバー（チャットと音声入力）が出る。もう一度クリックすると閉じる。
- カーソルを乗せて 0.2 秒待つ: 同じバーが出る。ペットとバーから離れて 0.4 秒で閉じる。クリックすると固定される。
- 右クリック: メニュー（設定・バーを隠す・位置をリセット・終了）。
- ドラッグ: つままれたポーズで動く。離すと置かれ、画面の外には出ない。位置は画面ごとに覚える。
- 放置: 設定「放置すると散歩する」がオンなら 90 秒ほどで散歩を始める。5 分ほどで眠る。
- 全画面のアプリを使っている間は譲る。閉じると前に戻る。

## Claude Code と連携する

hooks は `~/.claude/settings.json` に登録済み。登録し直すときは `pet-app.exe --install-hooks`、外すときは `--uninstall-hooks`。`pet-app.exe` を別の場所に移したら登録し直す（hook の項目には `pet-hook.exe` の絶対パスが入る）。

- Claude Code が動き出すとペットが作業のポーズになる。終わると 1 回喜んで「できたよ」、失敗すると「失敗しちゃった」。
- 承認待ちになるとペットがこちらを見て、吹き出しに承認のカード（ツール名と要約）が出る。
- 「許可」か「拒否」を押すと Claude Code がそのまま進む。「ターミナルで」（デスクトップアプリから来た要求では「Claude アプリで」）を押すと、いつもの画面で答える流れに戻る。
- 「許可」が無いカードは、要約が操作の全部を見せていない（Write や Edit の本文、長いコマンドなど）。そのときはいつもの画面で答える。
- 押さずに 1 分ほど放置すると、カードは下がり、Claude Code のいつもの流れに戻る。
- 同時に複数来たら古い順に 1 枚ずつ出す（「ほかに N 件」）。
- 質問（`AskUserQuestion`）は質問のカードになる。選択肢を押すか、「回答を書く…」でチャット欄に自由に書く。複数選択は選んでから「決定」。
- 質問のカードを出したくないときは設定「質問にペットで答える」をオフにする。「聞きたいことがあるよ」とだけ知らせる。
- 読み上げがオンなら、承認のカードは「確認してほしいことがあるよ」、質問は「聞きたいことがあるよ」と声でも知らせる。

## チャットする

送り先は Claude Code の対話と同じ環境（設定・CLAUDE.md・スキル・hooks・MCP）の新しいセッション。送るたびに `claude -p` を起こすので、答えまで 20 秒ほどかかることがある。

- バーの左のボタン（鉛筆）を押すと、ペットの下に入力欄が開く。
- 文を打って Enter か右の矢印ボタンで送る。2000 字まで。
- 答えは吹き出しに 1 行、入力欄の上の欄に全文が出る。吹き出しに収まらない答えは「続きを見る」で欄を開く。
- 続けて打つと同じ会話の続きになる。「新しいチャット」を押すと会話を忘れる。
- 入力欄の下の行で、左がモード、右がモデルとエフォート。押すとメニューが上に出る。数字キーでも選べる。
- ここで変えた値はそのチャットの間だけ効き、「新しいチャット」で設定画面の既定に戻る。
- 入力欄はペットを左クリックすると閉じる。Esc や外のクリックでは閉じない（日本語入力の取り消しに Esc を使うため）。
- 同じ hooks が効くので、チャットから承認待ちになるとペットの承認カードが出る。ファイルを書かせる作業はモードを「編集を受け入れる」にすると止まらない。
- 接続は設定「接続」で選ぶ。既定はサブスク（Claude Code にログインしているアカウント）。API キーを選ぶと使った分だけ課金される。
- 「いまの接続」の「確かめる」で、いまの接続で答えられるかを 15 秒以内に調べる。
- 作業フォルダは設定「作業フォルダ」。既定はホーム。選んだフォルダの CLAUDE.md と `.claude` も読む。

## 音声入力と読み上げ

### 音声入力（話してチャットに送る）

初回だけ `scripts\setup-stt.ps1` を PowerShell で 1 回実行する（文字起こしの Python 環境と faster-whisper small を用意する）。設定画面「音声入力」の行が「使えます」になれば準備できている。

- バーの右のボタン（波形）を押すと録音が始まり、ボタンが赤く脈打つ。
- 話し終えて 1 秒黙ると自動で止まり、文字起こしを経てチャットに送る。
- もう一度押すと、その場で止めて送る。
- 5 秒以内に話し始めないと取りやめる。1 回の録音は 15 秒まで。
- 聞き取った文は、入力欄の上の欄に「」付きで出てから答えが来る。
- マイクがミュートだと「マイクがミュートになっているよ」。Windows のサウンドの設定か、キーボードのミュートキーを見る。
- 録音はファイルに残さない。

### 読み上げ（声で知らせる）

設定「声で知らせる」をオンにする。声は AivisSpeech の天深シノ。

- 読むのは、チャットの答え（吹き出しの 1 行）と固定の文（できたよ・失敗しちゃった・入力を待ってるよ・確認してほしいことがあるよ・聞きたいことがあるよ）。
- 同じ文は 15 秒以内に繰り返さない。
- AivisSpeech エンジンが動いていなければペットが起こす（使えるまで 20 秒ほど）。ペットが起こしたエンジンは、10 分話さなければ止める（約 3.4GB のメモリを使うため）。
- エンジンの場所は `%USERPROFILE%\dev\voice\_engines\AivisSpeech\AivisSpeech-Engine\run.exe`。無いときは設定画面「読み上げ」の行に「エンジンが見つかりません」と出て、黙る。
- 答えに URL やパス、コードらしい文字列が入っていると、吹き出しには出さず「答えはチャット欄に出したよ」と言う。

## 設定画面

右クリックメニューかトレイの「設定」で開く。項目を変えるとすぐ効き、保存ボタンは無い。

| 節 | 項目 | 内容 |
|---|---|---|
| 表示 | ペット | 使うペットを選ぶ。足元の位置と大きさはそのまま |
| 表示 | ウェイクワード | 選んだペットの呼びかけの言葉を見るだけ（呼びかけで音声入力を始める機能は保留中） |
| 表示 | ペットの大きさ | 25〜150%。既定 55% |
| 表示 | 放置すると散歩する | 既定オフ。眠るのは設定に関係なく眠る |
| 起動 | サインインしたらペットを出す | Windows タスク `pet-claude` を登録する。実物はタスク スケジューラにあり、開くたびに読み直す |
| Claude Code | 質問にペットで答える | 既定オン。オフだと「聞きたいことがあるよ」と知らせるだけ |
| 声 | 声で知らせる | 読み上げのオン・オフ |
| 声 | 読み上げ | AivisSpeech の状態（使えます／エンジンは話す時に起こします／エンジンが見つかりません） |
| 声 | 音声入力 | 文字起こしの状態（使えます／準備が要ります／マイクが見つかりません／ミュート） |
| チャット | 接続 | サブスクか API キー。API キーは Windows の資格情報マネージャーに保存し、画面には読み返さない |
| チャット | いまの接続 | 「確かめる」で接続を試す |
| チャット | モデル | チャットの既定（Opus 5.5・Fable 5.1・Sonnet 5.5・Haiku 5.5）。既定 Fable 5.1 |
| チャット | エフォート | 低・中・高・最高・最大。既定 高 |
| チャット | モード | 権限モード（自動・手動・編集を受け入れる・プラン・権限をバイパス）。既定 自動 |
| チャット | 作業フォルダ | Claude Code を起こす場所。既定はホーム。「選ぶ」で変え、「既定に戻す」で戻す |

## ペットを切り替える・足す

- 切り替えは設定「ペット」。同梱は 6 体: まめドラゴン、りんりん（パンダ）、とらちゃん（茶トラ）、しばちゃん（黒柴）、こむぎちゃん（ハムスター茶）、ごまちゃん（ハムスター灰）。
- まだ選んでいなければまめドラゴンで起動する。
- 足すときは `%LOCALAPPDATA%\pet-claude\pets\<id>\` にペットのフォルダ（`pet.json` とスプライトシート）を置く。次に設定画面を開いたときに一覧に出る。
- 状態ごとの静止画（ファイル名に `idle` `walk` `working` `attention` `happy` `confused` `sleeping` `dragged` を含む PNG か WebP）から作るには、リポジトリで次を実行する。足りない状態は近い絵で埋める。

```bash
cargo run --release -p pet-core --example build_pet -- <静止画のフォルダ> <出力フォルダ> <id> <表示名>
```

- 姿勢の間を動画でつなぐペット（同梱の 6 体はこの形）の作り方は、プロジェクトスキル `.claude/skills/make-pet-clips/` と各ペットのフォルダの `SOURCE.md`。

## 困ったとき

| 症状 | 見るところ・やること |
|---|---|
| ペットが出ない | ログ `%LOCALAPPDATA%\pet-claude\logs\pet.log` の末尾。「既に起動しているので終了」ならもう出ている（別の画面か、全画面アプリの裏）。右クリックメニューの「位置をリセット」で手前の画面に戻る |
| 起動時にダイアログが出る | ペットを 1 つも読めない。`pets\<id>\pet.json` の場所と中身を確かめる。`--pet` で指定したフォルダが読めないときも同じ |
| 承認のカードが出ない | `pet-app.exe --install-hooks` を実行して登録を確かめる。`pet-hook.exe` が `pet-app.exe` と同じフォルダにあるか見る。ログに `permission requested` が無ければ hook が届いていない |
| チャットが「うまくいきませんでした」 | 入力欄の上の欄に理由が出る。設定「いまの接続」の「確かめる」を押す。`claude` が PATH にあるか、ログインが切れていないかを見る |
| 声が出ない | 設定「読み上げ」の行の状態を見る。エンジンの場所が違うなら上の「読み上げ」の節のパスに置く。Windows の出力デバイスも見る |
| 音声入力が動かない | 設定「音声入力」の行の状態を見る。「準備が要ります」なら `scripts\setup-stt.ps1` を実行する |
| 設定を最初からやり直したい | ペットを終了してから `%LOCALAPPDATA%\pet-claude\state.json` を消す（大きさ・位置・ペットの選択・チャットの既定が初期値に戻る。API キーは資格情報マネージャーに残る） |

ログには本文も答えも鍵も書かない。設定ファイルにも鍵は入らない。
