# pet-claude プロダクト要求定義書

## 1. 概要

K のデスクトップに常駐する小さなキャラクターが、Claude Code の作業状態に合わせて動き、承認待ちを吹き出しで知らせ、ペットから許可・拒否を返せる。声は ai-news と同じ AivisSpeech（天深シノ）。利用者は K 一人。配布しない。

## 2. 背景

ChatGPT のデスクトップアプリにはペット機能がある（他ウィンドウの上に浮かぶ・4 状態・`/pet`・1536×1872 の自作ペット）。Claude Code には同等機能が無く、第三者製は「日本語の声」と「ペットからの承認」を同時に満たすものが無い（偵察: `~/.agents/knowledge/scout/surveys/2026-10-21-claude-code-desktop-pet.md`）。

## 3. 目標と非目標

### 目標
- G1 Claude Code が何をしているか、画面の隅を見るだけで分かる
- G2 承認待ちを見逃さない（吹き出し＋声）。ペットから許可・拒否を返せる
- G3 声で話しかけ、声で返事が来る（AivisSpeech）
- G4 絵の差し替えで振る舞いが壊れない（素材と行動ロジックの分離）

### 非目標
- macOS / Linux
- 配布・インストーラ
- Claude Code 本体の `/buddy` の再現（ターミナル内ペット）
- OpenAI 側サービスとの連携

## 4. 利用者とシナリオ

利用者は K（Windows 11・複数ディスプレイ・表示倍率が画面ごとに違う）。

| # | シナリオ | ペットの反応 |
|---|---|---|
| S1 | Claude Code を使っていない | 呼吸・まばたき・ときどき座り直す。たまに散歩。長く放置すると眠る |
| S2 | プロンプトを送った | 起き上がって手元で作業する |
| S3 | ツールを実行している | 作業アニメーションを続ける |
| S4 | 承認や回答を待っている | こちらを見て小さく手を振る。吹き出し（ツール名＋要約）に「許可」「拒否」 |
| S5 | 応答が終わった | 一度だけリアクションして待機に戻る。声で短く知らせる |
| S6 | 失敗した | 失敗のポーズ。声で知らせる |
| S7 | クリックした | 喜ぶ・振り向く。下にバー（チャット／音声）が出る |
| S8 | ドラッグした | つままれたポーズ。離すと置かれる（画面外には出ない） |
| S9 | 右クリック | 設定／バーを非表示／終了 |
| S10 | バーの左（チャット） | 入力欄が開き、送るとペットが Claude に聞き、答えを吹き出しと声で返す |
| S11 | バーの右（音声入力） | 録音→文字起こし→S10 と同じ |
| S12 | 決めた言葉を言う（後回し） | 勝手に音声入力モードに入る |

## 5. 機能要件

### 5.1 表示（Phase 0・1）
- F1 透過・常時最前面・タスクバーに出ない
- F2 **フォーカスを奪わない**（クリックしても作業中のウィンドウからキーボードが離れない）
- F3 キャラクターの不透明部分だけがクリックを受け、透明部分は背後に通す
- F4 ドラッグで移動。複数ディスプレイの作業領域にクランプし、画面外に出ない。位置はディスプレイごとに保存
- F5 ディスプレイの追加・取り外し・倍率変更で位置を取り直す
- F6 全画面アプリ中に消えたまま戻らない事態を避ける（最前面の取り直し）

### 5.2 行動（Phase 1）
- F7 自律行動 4 種: 待機・散歩・睡眠・つままれ
- F8 Claude Code の状態に対する動き（§4 の S2〜S6）。優先順位: つままれ ＞ クリック反応 ＞ 承認待ち ＞ 失敗 ＞ 完了（1 回だけ） ＞ 作業中 ＞ 自律行動
- F9 素材は Codex ペット互換のスプライトシート（1536×1872・8 列×9 行・1 コマ 192×208）。睡眠・つままれは追加行（無ければ代替）
- F10 最初は仮画像（スクリプトで生成）で動作確認し、本番素材は後から差し替える

### 5.3 Claude Code 連携（Phase 2）
- F11 hooks で状態を受ける。hook は非同期・3 秒・常に exit 0。アプリが落ちていても Claude Code を止めない
- F12 入力部分は交換可能（hooks 以外の入力源に差し替えられる）
- F13 承認待ち（`PermissionRequest`）はペットの吹き出しから許可・拒否を返せる。一定時間で返事が無ければ通常の端末プロンプトに戻す
- F14 Claude Code のデスクトップアプリを閉じていても動く（独立プロセス・トレイ常駐）
- F15 `~/.claude/CLAUDE.md` には書かない。`settings.json` への hook 追記は管理マーカー付き・バックアップ付き

### 5.4 声と会話（Phase 3）
- F16 音声出力: AivisSpeech（`127.0.0.1:10101`・天深シノ・ノーマル）。エンジンが起動していなければ黙って無効
- F17 音声入力: バーの右ボタンで録音→ローカルで文字起こし（日本語）
- F18 チャット: バーの左ボタンで入力欄→Claude に送る→答えを吹き出し＋声
- F19 設定画面: ペットの大きさ、音声出力の有無、音声トリガーの有無

### 5.5 ウェイクワード（Phase 4）
- F20 K の声を録音し、決めた言葉で音声入力モードに入る。既定は OFF

## 6. 非機能要件
- N1 常駐時の CPU は 1 コアの 2% 以下。メモリは子プロセスを含めた専有メモリで、普段（UI を出していない間）50MB 以下、UI を出している間 150MB 以下（2026-10-21 改訂: UI の WebView2 は使うときだけ作るので、普段と表示中を分けた。旧「150MB 以下」は WebView2 の子プロセスを数えていなかった）
- N2 hook の実行時間は 200ms 以内（Claude Code の体感を落とさない）
- N3 吹き出しに表示する動的テキストは検証する（1〜140 字・単一行・コード/URL/パス/秘密らしい文字列は拒否）
- N4 ログ・設定に秘密を書かない
- N5 Windows タスクでの自動起動は `run-hidden.vbs` 経由（窓を出さない）

## 7. 受け入れ条件（Phase ごと）

| Phase | 条件 |
|---|---|
| 0 土台 | 2 画面×倍率違いで、F1〜F6 のチェックリストが全て PASS（スクショ付き） |
| 1 行動 | 仮画像で F7〜F10。状態機械の `cargo test` が通る |
| 2 連携 | 実セッションで S2〜S6 が動く。承認を吹き出しから返して端末側が進む。アプリ停止中に hook が 200ms 以内で exit 0（故障注入） |
| 3 声 | S10・S11 が動く。AivisSpeech 停止中でも落ちない |
| 4 覚醒語 | K の声で 10 回中 9 回以上反応、無関係な会話で 10 分に 1 回以下の誤反応 |
